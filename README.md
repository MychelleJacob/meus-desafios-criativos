# meus-desafios-criativos
automação de gestão acadêmica no n8n. O principal ajuste é transformar o objetivo de “registrar comunicações” em um processo estruturado de monitoramento do fluxo de produção, revisão e qualidade dos conteúdos acadêmicos, usando o Jira como fonte de informações e o Google Sheets como painel de acompanhamento.
